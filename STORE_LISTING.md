# Chrome Web Store Listing for TempMail Pro

## Store Description

**Short Description (132 characters max):**
Create and manage temporary email addresses from multiple providers. Protect your privacy with disposable emails.

**Detailed Description:**

TempMail Pro is the ultimate Chrome extension for creating and managing temporary email addresses. Protect your privacy and avoid spam by using disposable emails for signups, downloads, and online services.

🌟 **Key Features:**
• Create temporary email addresses instantly
• Support for 5 major providers (Guerrilla Mail, Mail.gw, DropMail.me, Mail.tm, TempMail.lol)
• Real-time inbox monitoring with auto-refresh
• One-click email address copying
• View both HTML and raw message content
• Desktop notifications for new messages
• No registration or personal information required

🔒 **Privacy-First Design:**
• All data stored locally in your browser
• No tracking or analytics
• No personal information collected
• Open source for complete transparency

⚡ **Easy to Use:**
• Clean, intuitive interface
• Multiple email providers in one extension
• Automatic email expiration handling
• Background monitoring for new messages

Perfect for:
✓ Online shopping and signups
✓ Downloading free resources
✓ Testing web applications
✓ Avoiding spam in your main inbox
✓ Protecting your privacy online

## Permissions Justification

**Storage:** To save temporary email addresses and user preferences locally
**Alarms:** To schedule automatic inbox refresh intervals
**Notifications:** To alert users when new messages arrive
**Clipboard Write:** To enable one-click copying of email addresses
**Host Permissions:** To communicate with temporary email service APIs (guerrillamail.com, mail.gw, dropmail.me, mail.tm, tempmail.lol)
